Aether — Interactive Particle & Flow Field Studio

An interactive, canvas-based generative art experience featuring dynamic particle flow physics, visual force fields, and interactive constellation networks. Built using pure JavaScript, HTML5 Canvas, and Tailwind CSS.

✨Key Features

Interactive Particle Physics: Particles dynamically react to cursor and touch movement in real-time.

Three Flow Modes: Switch between Attract, Vortex, and Repel physics behaviors.

Vibrant Color Palettes: Instantly toggle between four neon glow themes (Neon Orchid, Cyber Emerald, Solar Flare, Cosmic Violet).

Constellation Network: Automatic line connections form dynamic visual structures between nearby particles.

Mobile & Touch Responsive: Full touch-event support optimized for phones, tablets, and desktops.

Zero External Dependencies: Lightweight code powered by pure HTML5 Canvas and Tailwind CSS CDN.

🚀Quick Setup & Deployment

Run Locally

Download or clone this repository.

Open index.html directly in any web browser.

Host on GitHub Pages

Upload index.html and README.md to your GitHub repository.

Go to Settings ➔ Pages.

Under Build and deployment, select Deploy from a branch and choose main / / (root).

Click Save to launch your live site.
